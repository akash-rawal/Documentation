With full support for **SAM 3 (Segment Anything Model 3)**, you can now use existing annotations as visual prompts to automatically segment similar objects across the same image.

**How to Use:**
1. Draw a bounding box or polygon annotation on a reference object.
2. Select the annotation and press **I** on your keyboard.
3. SAM 3 automatically identifies similar visual signatures and generates segmentation masks for all matching instances in the canvas.

**Benefits:**
- Saves hours of manual tracing on repetitive items (e.g., vehicles, shelf products, tools).
- Ensures boundary and mask quality consistency.

SAM 3 now supports text-driven object annotation inside Labellerr, allowing you to label objects by typing their semantic name.

**How to Use:**
1. Select **SAM 3** and choose the **Text Prompt** option.
2. Enter the name of the object category (e.g., *"dice"*, *"car"*, *"furniture"*).
3. The platform automatically localizes and segments the target objects.

**Benefits:**
- Highly flexible for datasets with clearly defined semantic categories.
- Eliminates manual clicking/drawing by relying on text-to-segmentation models.

## FAQs

**Q1. How does the new Master Control help with video QA?**
It displays all active events on a frame-by-frame basis in a centralized panel, allowing reviewers to correct temporal boundaries (start/end frames) and edit metadata without opening multiple side panels.

**Q2. What is the keyboard shortcut to trigger visual prompt labeling?**
Select an existing annotation and press **I** on your keyboard to trigger SAM 3 to find and segment similar objects in the image.

**Q3. Can I use text prompt segmentation for custom objects?**
Yes, SAM 3's zero-shot capabilities allow it to segment a wide variety of common and custom objects based on standard English names.
